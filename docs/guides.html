Before you start

Two links do almost everything. Both refresh automatically, so anything you build on them stays current.

countries.csv

One row per country or area, 31 columns. Use it for filters, slicers, labels, and to add region or income to your own data by iso3.

https://mafiatun.github.io/country-classification-commons/data/countries.csv

country_group_membership.csv

One row per country and group. Use it for any grouping that is not a column, such as SDG regions or OECD DAC groups, and for many-to-many models.

https://mafiatun.github.io/country-classification-commons/data/country_group_membership.csv

Four things that trip people up

  1. Namibia's ISO2 code is NA. pandas and R read it as missing unless you tell them not to. Every snippet on this page handles it.
  2. Keep codes as text. M49 codes have leading zeros (004 is Afghanistan). Read m49 as text, and join on iso3 when you can.
  3. Flags are true/false. Most tools turn them into real booleans. If yours keeps them as text, compare with "true".
  4. Files are UTF-8. Names like Côte d’Ivoire, Türkiye and the Arabic and Chinese columns need UTF-8 (code page 65001 in Excel and Power BI).

Need a fixed version for a paper or an audit? Every refresh is archived. Replace main/data/latest/ in https://raw.githubusercontent.com/MafiAtUN/country-classification-commons/main/data/latest/countries.csv with main/data/history/<snapshot>/, using a folder name from data/history. The GitHub raw links (https://raw.githubusercontent.com/MafiAtUN/country-classification-commons/main/data/latest/…) also work everywhere the short links do.

BI tools

Power BI

Connect once with the Web connector. Power BI Desktop and the Power BI service both refresh from the same link, no gateway needed.

  1. Get data › Web, paste the countries.csv link, choose Anonymous. Click Transform data.
  2. In Power Query, check that m49 is Text and the is_… columns are True/False. Or open Advanced editor and paste the query below, which sets the types for you.
  3. Rename the query countries. Repeat for country_group_membership.csv and name it membership (second tab below).
  4. In Model view: countries[iso3] 1 → * yourdata[iso3]. For groups that are not columns, add membership[iso3] * → 1 countries[iso3] and set Cross filter direction to Both. A slicer on membership[group_name] now filters your data.
  5. Put countries[is_un_member] in the filter pane (page or report level) and set it to True. Every visual now counts 193 States, and Africa shows 54.
  6. Publish. In the service, set the data source credentials to Anonymous and privacy level Public, then schedule refresh.
let
    Base = "https://mafiatun.github.io/country-classification-commons/data/",
    // RelativePath keeps the data source static, so scheduled refresh works in the Power BI service
    Source = Csv.Document(
        Web.Contents(Base, [RelativePath = "countries.csv"]),
        [Delimiter = ",", Encoding = 65001, QuoteStyle = QuoteStyle.Csv]),
    Promoted = Table.PromoteHeaders(Source, [PromoteAllScalars = true]),
    Typed = Table.TransformColumnTypes(Promoted, {
        {"m49", type text}, {"is_un_member", type logical}, {"is_ldc", type logical},
        {"is_lldc", type logical}, {"is_sids", type logical}, {"is_fcs", type logical},
        {"is_oda_eligible", type logical}, {"is_oecd_member", type logical},
        {"latitude", type number}, {"longitude", type number}}, "en-US")
in
    Typed
let
    Base = "https://mafiatun.github.io/country-classification-commons/data/",
    Source = Csv.Document(
        Web.Contents(Base, [RelativePath = "country_group_membership.csv"]),
        [Delimiter = ",", Encoding = 65001, QuoteStyle = QuoteStyle.Csv]),
    Promoted = Table.PromoteHeaders(Source, [PromoteAllScalars = true]),
    // Keep only what the bridge needs; country details come from the countries table
    Kept = Table.SelectColumns(Promoted, {"iso3", "group_id", "group_name", "source", "group_type"})

BI tools

Tableau

Tableau Desktop cannot open a CSV straight from a web link, so pick the route that fits how often you refresh.

Route A: download and connect

  1. Download countries.csv and, if needed, country_group_membership.csv.
  2. Connect › Text file and open countries.csv. Add your own data source.
  3. To refresh later, download again over the same file and choose Data › Refresh.

Route B: Google Sheets, refreshes itself

  1. In a new Google Sheet, cell A1: =IMPORTDATA("https://mafiatun.github.io/country-classification-commons/data/countries.csv")
  2. In Tableau: Connect › Google Drive and pick that sheet.
  3. Publish to Tableau Cloud or Server with an extract refresh schedule.

Model it

  1. On the data source page, drag both tables onto the canvas and use a relationship (the noodle, not a join) on iso3 = iso3. Relationships keep country counts right when one country belongs to many groups.
  2. Check that is_un_member came in as Boolean. If it shows as text, change its type to Boolean. Set m49 to String.
  3. Right-click iso3 › Geographic role › Country/Region. Tableau recognises ISO3 codes, so maps work without any extra setup.
  4. Drag is_un_member to Filters and keep True. Then Add to context so it applies before other filters.
// Readable UN status for tooltips
CASE [un_status]
  WHEN "member_state"   THEN "UN Member State"
  WHEN "observer_state" THEN "UN observer State"
  ELSE "Not a UN Member State"
END

// Count of UN Member States, whatever else is filtered
{ FIXED : COUNTD( IF [is_un_member] THEN [iso3] END ) }

BI tools

Qlik Sense

Qlik links tables automatically on matching field names, so the only care needed is loading the right fields.

  1. Quick route: Add data › Web file, paste the countries.csv link, set Field names: Embedded and Character set: UTF-8.
  2. Scripted route (repeatable, schedulable): create two Web file connections and use the load script below.
  3. Your own table should have a field called iso3. Qlik associates it with countries on its own.
  4. Flags arrive as the text 'true'/'false'; set analysis compares them directly.
// Data load editor. First create a "Web file" connection for each link:
//   Create new connection > Web file > URL: https://mafiatun.github.io/country-classification-commons/data/countries.csv         > Name: CCC countries
//   Create new connection > Web file > URL: https://mafiatun.github.io/country-classification-commons/data/country_group_membership.csv > Name: CCC membership

countries:
LOAD *
FROM [lib://CCC countries]
(txt, utf8, embedded labels, delimiter is ',', msq);

// Load only the bridge fields. Loading iso2, m49 or country_name again
// would create a synthetic key, because Qlik links tables on every shared field name.
membership:
LOAD iso3, group_id, group_name, source AS group_source, group_type
FROM [lib://CCC membership]
(txt, utf8, embedded labels, delimiter is ',', msq);
// UN Member States only, straight from the load
un_countries:
NoConcatenate
LOAD * RESIDENT countries
WHERE is_un_member = 'true';
DROP TABLE countries;
RENAME TABLE un_countries TO countries;
// Chart expressions
Count({<is_un_member={'true'}>} DISTINCT iso3)                     // 193
Count({<is_un_member={'true'}, region={'Africa'}>} DISTINCT iso3)  // 54

Spreadsheets

Excel

Power Query brings the table in and refreshes it on demand or on open. Formulas do the rest.

  1. Data › Get Data › From Other Sources › From Web, paste the countries.csv link, then Transform Data.
  2. Set m49 to Text (Power Query guesses Whole Number and drops the leading zeros), then Close & Load to a table. Name the table countries.
  3. Refresh with Data › Refresh All. In Query Properties you can tick Refresh data when opening the file.
  4. Or paste the Power Query from the Power BI section into Advanced Editor. Excel uses the same engine.
// How many UN Member States in Africa?
=COUNTIFS(countries[region], "Africa", countries[is_un_member], TRUE)          → 54

// List them
=FILTER(countries[name], (countries[region] = "Africa") * countries[is_un_member])

// Add the World Bank income group next to your own data (ISO3 in column A)
=XLOOKUP(A2, countries[iso3], countries[wb_income_group], "not found")

// Is this row a UN Member State?
=XLOOKUP(A2, countries[iso3], countries[is_un_member], FALSE)

Spreadsheets

Google Sheets

One formula. Sheets re-fetches the file about once an hour while the spreadsheet is open.

  1. Rename a tab countries and type in A1: =IMPORTDATA("https://mafiatun.github.io/country-classification-commons/data/countries.csv")
  2. Columns follow the file: A iso3, B iso2, C m49, D name, E un_status, F is_un_member, G un_regional_group, H region, I sub_region. The data dictionary lists all 31.
  3. IMPORTDATA turns m49 into numbers. Use TEXT(C2, "000") when you need the three-digit code.
// UN Member States in Africa → 54
=COUNTIFS(countries!H:H, "Africa", countries!F:F, TRUE)

// The list, sorted
=SORT(FILTER(countries!D2:D, countries!H2:H = "Africa", countries!F2:F = TRUE))

// Add the M49 sub-region to your data (ISO3 in column A)
=XLOOKUP(A2, countries!A:A, countries!I:I, "not found")

Code

Python

pandas, polars or DuckDB read the links directly. No download step, no API key.

import pandas as pd

base = "https://mafiatun.github.io/country-classification-commons/data/"
# keep_default_na=False keeps Namibia's ISO2 "NA"; m49 as text keeps leading zeros
opts = dict(keep_default_na=False, dtype={"m49": str})
countries = pd.read_csv(base + "countries.csv", **opts)
members = pd.read_csv(base + "country_group_membership.csv", **opts)

# 1. Only UN Member States
un = countries[countries.is_un_member]                      # 193 rows

# 2. Africa, UN Member States only
africa = un[un.region == "Africa"]                          # 54 rows

# 3. Add classifications to your own data
mydata = pd.DataFrame({"iso3": ["KEN", "FRA", "REU"], "value": [1.2, 3.4, 5.6]})
enriched = mydata.merge(countries[["iso3", "name", "region", "wb_income_group", "is_un_member"]],
                        on="iso3", how="left", validate="many_to_one")

# 4. Average by every group each country belongs to, including groups that are not columns
by_group = (mydata.merge(members[["iso3", "group_id", "group_name"]], on="iso3")
                  .groupby("group_name")["value"].mean())
import polars as pl

base = "https://mafiatun.github.io/country-classification-commons/data/"
countries = pl.read_csv(base + "countries.csv", schema_overrides={"m49": pl.Utf8})

africa = countries.filter((pl.col("region") == "Africa") & pl.col("is_un_member"))
print(africa.height)  # 54
import duckdb

duckdb.sql("""
    SELECT un_regional_group, count(*) AS n
    FROM read_csv('https://mafiatun.github.io/country-classification-commons/data/countries.csv', types = {'m49': 'VARCHAR'})
    WHERE is_un_member
    GROUP BY ALL ORDER BY n DESC
""").show()

R

readr and dplyr, or data.table. Both read the link directly.

library(readr)
library(dplyr)

base <- "https://mafiatun.github.io/country-classification-commons/data/"
# na = "" keeps Namibia's ISO2 "NA"; m49 as text keeps leading zeros
countries <- read_csv(paste0(base, "countries.csv"), na = "", col_types = cols(m49 = "c"))
members   <- read_csv(paste0(base, "country_group_membership.csv"), na = "", col_types = cols(m49 = "c"))

# Africa, UN Member States only
africa <- countries |> filter(region == "Africa", is_un_member)
nrow(africa)  # 54

# Add classifications to your own data
mydata <- tibble(iso3 = c("KEN", "FRA", "REU"), value = c(1.2, 3.4, 5.6))
enriched <- mydata |>
  left_join(select(countries, iso3, name, region, wb_income_group, is_un_member),
            by = "iso3", relationship = "many-to-one")

# Average by any group in the long table
by_group <- mydata |>
  inner_join(select(members, iso3, group_id, group_name), by = "iso3") |>
  summarise(value = mean(value), .by = group_name)

Julia

CSV.jl and DataFrames.jl. Downloads ships with Julia.

using CSV, DataFrames, Downloads

base = "https://mafiatun.github.io/country-classification-commons/data/"
load(file) = CSV.read(Downloads.download(base * file), DataFrame; types = Dict(:m49 => String))
countries = load("countries.csv")
members = load("country_group_membership.csv")

# Africa, UN Member States only
# isequal, not ==: empty cells (Antarctica has no region) load as missing
africa = filter(r -> isequal(r.region, "Africa") && r.is_un_member, countries)
nrow(africa)  # 54

# Add classifications to your own data
mydata = DataFrame(iso3 = ["KEN", "FRA", "REU"], value = [1.2, 3.4, 5.6])
enriched = leftjoin(mydata, select(countries, :iso3, :name, :region, :wb_income_group), on = :iso3)

# Average by any group in the long table
by_group = combine(groupby(innerjoin(mydata, select(members, :iso3, :group_name), on = :iso3), :group_name),
                   :value => (v -> sum(v) / length(v)) => :mean_value)

JavaScript

Fetch the JSON for apps, or the CSV with d3 for notebooks and Observable.

// Browser or Node 18+. The site serves files with CORS enabled.
// The JSON copy has real booleans and numbers, so it is the easiest format in JavaScript.
const base = "https://mafiatun.github.io/country-classification-commons/data/";
const countries = await (await fetch(base + "countries.json")).json();

const africa = countries.filter((c) => c.region === "Africa" && c.is_un_member);
console.log(africa.length); // 54

// Look up a country by ISO3
const byIso3 = new Map(countries.map((c) => [c.iso3, c]));
byIso3.get("REU").un_status; // "non_member"
import * as d3 from "https://cdn.jsdelivr.net/npm/d3@7.9.0/+esm";

const base = "https://mafiatun.github.io/country-classification-commons/data/";
const members = await d3.csv(base + "country_group_membership.csv");

// Countries per group, UN Member States only
const counts = d3.rollup(
  members.filter((m) => m.is_un_member === "true"),
  (rows) => rows.length,
  (m) => m.group_name
);
counts.get("Least Developed Countries (LDC)"); // 44

SQL

DuckDB queries the link as if it were a table. For PostgreSQL, load it once with \copy.

-- DuckDB (CLI, Python, R or the browser). Reads straight from the URL.
CREATE VIEW countries AS
  SELECT * FROM read_csv('https://mafiatun.github.io/country-classification-commons/data/countries.csv', types = {'m49': 'VARCHAR'});
CREATE VIEW members AS
  SELECT * FROM read_csv('https://mafiatun.github.io/country-classification-commons/data/country_group_membership.csv', types = {'m49': 'VARCHAR'});

-- Africa, UN Member States only → 54
SELECT name, iso3 FROM countries WHERE region = 'Africa' AND is_un_member ORDER BY name;

-- Which African areas are not UN Member States?
SELECT name, un_status FROM countries WHERE region = 'Africa' AND NOT is_un_member;

-- Members of any group, by id
SELECT country_name FROM members WHERE group_id = 'un_membership.regional_group.apg';
-- PostgreSQL via psql. \copy runs on your machine, so it needs no superuser rights.
CREATE TABLE countries (
  iso3 char(3) PRIMARY KEY, iso2 char(2), m49 char(3), name text,
  un_status text, is_un_member boolean, un_regional_group text,
  region text, sub_region text, intermediate_region text, analysis_region text, sdg_region text,
  is_ldc boolean, is_lldc boolean, is_sids boolean,
  wb_region text, wb_income_group text, wb_lending_type text,
  is_fcs boolean, fcs_category text, is_oda_eligible boolean, oda_recipient_group text, is_oecd_member boolean,
  capital text, latitude double precision, longitude double precision,
  name_ar text, name_zh text, name_fr text, name_ru text, name_es text
);

import delimited "https://mafiatun.github.io/country-classification-commons/data/countries.csv", clear varnames(1) encoding("utf-8") stringcols(3)

foreach v of varlist is_* {

}
