How many countries are in Africa?

54 if you ask the UN General Assembly. 60 if you ask the UN statistical standard (M49). 48 if you ask the World Bank about Sub-Saharan Africa. Every answer is official. This project puts every official grouping in one open table, so you choose the definition on purpose instead of by accident.

The fix is one column

Every row knows if it is a UN Member State

The UN statistical standard (M49) lists 248 countries and areas, including Réunion, Western Sahara and Greenland. That is right for statistics and wrong for a list of Member States. Every file here carries un_status, so the filter you need is one line in any tool.

  • member_state193UN Member States. The list the General Assembly uses.
  • observer_state2Holy See and State of Palestine, non-member observer States.
  • non_member53Territories and other areas in M49, kept for statistics.
import pandas as pd

url = "https://mafiatun.github.io/country-classification-commons/data/countries.csv"
countries = pd.read_csv(url, keep_default_na=False)

africa = countries[(countries.region == "Africa") & countries.is_un_member]
len(africa)  # 54
library(readr); library(dplyr)

url <- "https://mafiatun.github.io/country-classification-commons/data/countries.csv"
countries <- read_csv(url, na = "")

africa <- countries |> filter(region == "Africa", is_un_member)
nrow(africa)  # 54

Straight from the publishers

Every run pulls the current lists, records what changed, and keeps a dated snapshot. Nothing is typed in by hand except the two short lists no publisher offers as data.

Nerd Lab is an open playground for colleagues who like to build things to find out how they work. This one exists because “Africa” can mean 54 countries in one report and 60 in the next dataset, and nobody says which. Everything here is open source.
